# เว็บไซต์ตรวจผลสลากกินแบ่งรัฐบาลไทย (Thai Government Lottery Web)
เชื่อมต่อฐานข้อมูลโดยตรงจากสำนักงานสลากกินแบ่งรัฐบาล (GLO Official Open API)

---

## จุดเด่นและคุณสมบัติของระบบ

1. **ดึงผลสลากกินแบ่งรัฐบาลสดจาก GLO ครบทุกรางวัล:**
   - เชื่อมต่อ API อย่างเป็นทางการของสำนักงานสลากกินแบ่งรัฐบาล (`https://www.glo.or.th/api/lottery/getLatestLottery` และ `https://www.glo.or.th/api/checking/getLotteryResult`)
   - แสดงผลครบทุกรางวัล: รางวัลที่ 1 (6,000,000 บ.), ข้างเคียงรางวัลที่ 1 (100,000 บ.), รางวัลที่ 2-5, เลขหน้า 3 ตัว, เลขท้าย 3 ตัว, เลขท้าย 2 ตัว
   - ลิงก์ดาวน์โหลดใบตรวจรางวัลทางการ (PDF เรียงเบอร์) และลิงก์ถ่ายทอดสด / เทปบันทึกภาพจาก GLO

2. **ระบบตรวจสลากกินแบ่งที่ตรวจได้จริงและแม่นยำ 100%:**
   - **ตรวจแบบรายใบ (Single Check):** กรอกเลข 6 หลัก เลือกรอบงวด กดตรวจได้ทันที พร้อมแสดงเอฟเฟกต์พลุกระดาษ (Confetti) เมื่อถูกรางวัล
   - **ตรวจหลายใบพร้อมกัน (Bulk Check):** สามารถวางหมายเลขสลากพร้อมกันได้ถึง 50 ใบ ระบบจะคำนวณสรุปเงินรางวัลรวมทั้งหมดให้ทันที
   - ตรวจสอบซ้อนรางวัลได้ถูกต้องตามกฎเกณฑ์สลาก เช่น ใบที่ถูกรางวัลที่ 1 และเลขท้าย 2 ตัว พร้อมกัน

3. **ระบบอัปเดตอัตโนมัติทุกงวด (วันที่ 1 และ 16 ของเดือน):**
   - มี Background Scheduler ทำงานตรวจเช็กและซิงก์ผลรางวัลสดในเวลาออกรางวัล (14:30 - 17:00 น.) ทุกวันที่ 1 และ 16 ของเดือน
   - มีระบบตรวจเช็กอัปเดตประจำวันเวลา 06:00 และ 18:00 น.
   - นาฬิกานับถอยหลัง (Countdown) สู่งวดถัดไปแบบอัตโนมัติ

4. **มาตรฐานความปลอดภัยระดับสูง ป้องกันแฮกเกอร์ (Enterprise Security):**
   - **ป้องกัน Brute-force & DDoS:** ระบบจำกัดอัตราการยิงคำขอ (Rate Limiter) 60 ครั้ง/นาที สำหรับตรวจรางวัล และ 5 ครั้ง/นาที สำหรับล็อกอิน
   - **ระบบล็อกบัญชีอัตโนมัติ (Lockout):** หากใส่รหัสผ่านแอดมินผิดเกิน 5 ครั้ง ระบบจะล็อกการเข้าถึง 15 นาที
   - **ป้องกัน CSRF:** มีการตรวจสอบ CSRF Token ทุกแบบฟอร์มและการส่งข้อมูล
   - **ป้องกัน SQL Injection:** ใช้ Parameterized Queries ผ่าน SQLite 100%
   - **HTTP Security Headers:** ติดตั้ง Content-Security-Policy (CSP), X-Frame-Options (ป้องกัน Clickjacking), X-Content-Type-Options (nosniff)
   - **การเข้ารหัสรหัสผ่าน:** ใช้การแฮชมาตรฐานระดับสูง (Scrypt / PBKDF2) ไม่มีจัดเก็บรหัสผ่านเป็น Plaintext

5. **แผงควบคุมผู้ดูแลระบบ (Admin Dashboard) — คุณคนเดียวเท่านั้นที่แก้ไขได้:**
   - เข้าสู่ระบบผ่าน URL: `/admin/login`
   - **บัญชีเริ่มต้น:**
     - ผู้ใช้: `admin`
     - รหัสผ่าน: `Admin@Lottery#2026` *(แนะนำให้เปลี่ยนหลังเข้าสู่ระบบครั้งแรก)*
   - สามารถ:
     - กดปุ่ม **"ดึงผลรางวัลงวดล่าสุดทันที (Force Sync)"** จาก GLO ได้ตามต้องการ
     - กดปุ่ม **"ดึงผลงวดย้อนหลัง 6 เดือน"**
     - แก้ไขชื่อเว็บไซต์ (Website Title)
     - แก้ไขหรือเปิด/ปิดแถบประกาศสีส้มหน้าแรก (Announcement Bar)
     - เปลี่ยนรหัสผ่านแอดมินใหม่
     - ดูบันทึกความปลอดภัยและประวัติการทำงาน (Security Audit Logs)

## โครงสร้างโปรเจกต์

```
thai-lottery-web/
├── app.py                  # แอปพลิเคชันหลัก Flask, API Endpoints, Routing
├── config.py               # การตั้งค่าความปลอดภัยและ API GLO
├── database.py             # ฐานข้อมูล SQLite, Schema, จัดเก็บผลรางวัล และระบบล็อกอิน
├── glo_service.py          # ตัวเชื่อมต่อ API GLO ทางการ และตรรกะการตรวจรางวัล
├── scheduler.py            # ตัวตั้งเวลาดึงผลรางวัลอัตโนมัติทุกวันที่ 1 และ 16
├── security.py             # ระบบ Rate Limiter, CSRF Token, และ Security Headers
├── test_app.py             # ชุดทดสอบระบบอัตโนมัติ (Unit & Integration Tests)
├── run.bat                 # สคริปต์เปิดรันเซิร์ฟเวอร์บน Windows
├── lottery.db              # ฐานข้อมูลผลรางวัลและข้อมูลระบบ
├── templates/              # หน้าเว็บ HTML (Jinja2)
│   ├── base.html           # แม่แบบหลักพร้อมโครงสร้างความปลอดภัย
│   ├── index.html          # หน้าแรก ตรวจรางวัล ตารางรางวัลครบทุกหมวด
│   ├── check.html          # หน้าตรวจสลากหลายใบพร้อมกัน
│   ├── history.html        # หน้าคลังสถิติผลหวยย้อนหลัง
│   ├── admin_login.html    # หน้าล็อกอินผู้ดูแลระบบ
│   └── admin_dashboard.html# หน้าแผงควบคุมแอดมิน
└── static/
    ├── css/
    └── js/
        └── app.js          # สคริปต์ตรวจหวยแบบเรียลไทม์ และลูกเล่น Confetti
```

## วิธีเปิดใช้งานเว็บไซต์

### 1. รันผ่านไฟล์ run.bat
ดับเบิลคลิกที่ไฟล์ `run.bat` หรือเปิดผ่าน Terminal:
```powershell
cd C:\Users\MIN\.gemini\antigravity\scratch\thai-lottery-web
python app.py
```

### 2. เปิดดูในเว็บเบราว์เซอร์
- **หน้าเว็บสำหรับประชาชนทั่วไป:** [http://localhost:5000](http://localhost:5000)
- **หน้าจัดการแอดมิน (เฉพาะคุณ):** [http://localhost:5000/admin](http://localhost:5000/admin)
